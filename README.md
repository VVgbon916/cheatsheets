## 💖 Avalhla AI: Persistent Memory Suite

Avalhla features a **3-Layer Memory Architecture** that remembers Dawa across terminal reboots:

```
~/.ai-memory/
├── profiles/user-profile.txt       # Dawa's hardware, coding preferences & specs
├── system-prompt.txt               # Avalhla's cute nerdy bestie persona
├── conversations/*.jsonl           # Timestamped conversation logs
└── knowledge-base/                 # Indexed scripts, bibles, and documentation
```

### CLI AI Commands:
- **`ai-with-memory`** — Start an interactive chat session with Avalhla (she remembers previous topics and user profile).
- **`ai-learn <path>`** — Indexes any code or documentation folder into Avalhla's long-term memory.
- **`ai-remember`** — Avalhla self-reflects on past chats and summarizes what she has learned about Dawa.
- **`ai-progress`** — Displays learning statistics, total message count, and knowledge base size.
