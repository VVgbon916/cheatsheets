+==================================================================================================+
|  SECTION 01  //  SERVER  —  start, stop, verify                                                  |
+==================================================================================================+

    avastart                    boot Ollama + launch Avalhla (once per boot)
    avastop                     stop server, free VRAM (~5.5 GB back)
    ollama list | grep avalhla  check she exists
    ollama ps                   see running models
    curl -fsS http://127.0.0.1:11434/api/tags    is server up?

    # Manual fallback if avastart fails
    pkill -f "ollama serve"
    OLLAMA_CONTEXT_LENGTH=16384 OLLAMA_NUM_GPU=999 nohup ollama serve > ~/.ollama/serve.log 2>&1 &
    until curl -fsS http://127.0.0.1:11434/api/tags >/dev/null 2>&1; do sleep 1; done
    echo "Ollama is ready"


+==================================================================================================+
|  SECTION 02  //  TALK TO HER  —  chat modes                                                      |
+==================================================================================================+

    ollama run avalhla                  interactive chat
    ollama run avalhla "question"       one-shot question

    Inside >>> prompt:
    /bye            exit cleanly (server keeps running)
    Ctrl+D          same as /bye
    Ctrl+C          force quit if stuck
    /?              help menu
    /clear          wipe chat context
    /show info      model details

    research <url>                      default = Java/Bash API patterns

    # 3. Test review() — she reads a file and comments

    # 4. Test research() — she fetches a URL

    # 5. Exit and clean up

    # If any of these hang: check server is running (ollama ps).
    # If any return empty: check jq is installed (which jq).

+==================================================================================================+
|  SECTION 08  //  TROUBLESHOOT  —  one fix per symptom                                            |
+==================================================================================================+

    SYMPTOM: "could not connect to ollama server"
    FIX:     Not an error. Start it: avastart

    SYMPTOM: Empty response from ai()
    FIX:     Check jq: which jq
             Check server: curl -fsS http://127.0.0.1:11434/api/tags
             Check model: ollama list | grep avalhla

    SYMPTOM: Wrong hardware / wrong personality
    FIX:     cd ~/projects/cheatsheets
             ollama create avalhla -f persona/avalhla.Modelfile

    SYMPTOM: Slow generation
    FIX:     Close Firefox, OBS, games. Check nvidia-smi.

    SYMPTOM: OOM / GPU spillover
    FIX:     avastop. Close apps. avastart.
             Or lower num_ctx to 8192 in Modelfile and rebuild.

    SYMPTOM: Nuclear reset
    FIX:     ollama rm avalhla
             ollama create avalhla -f persona/avalhla.Modelfile
