+==================================================================================================+
|  QUICK COMMANDS  //  the ones you'll actually type daily                                          |
+==================================================================================================+

    avastart                    boot container + launch Avalhla
    avastop                     stop container (frees VRAM)

    ollama run avalhla          chat with her
    ollama run avalhla "..."    one-shot question

    ai-chat                     persistent memory chat
    ai-learn <path>             index a file/folder
    ai-remember                 she reflects on recent sessions
    ai-ask "question"           one-shot with context


+==================================================================================================+
|  SERVER  //  systemd user service for Ollama container                                            |
+==================================================================================================+

    systemctl --user start ollama.service       boot the container
    systemctl --user stop ollama.service        stop (free ~5.5 GB VRAM)
    systemctl --user restart ollama.service     restart
    systemctl --user status ollama.service      is it running?

    # Auto-updates at midnight via:
    systemctl --user status podman-auto-update.timer


+==================================================================================================+
|  CHAT  //  interactive + one-shot                                                                 |
+==================================================================================================+

    ollama run avalhla                          interactive
    ollama run avalhla "your question"          one-shot

    Inside >>> prompt:
    /bye            exit cleanly (server keeps running)
    Ctrl+D          same as /bye
    Ctrl+C          force quit if stuck
    /?              help menu
    /clear          wipe current chat context
    /show info      model details


+==================================================================================================+

+==================================================================================================+

+==================================================================================================+
|  TROUBLESHOOT  //  one fix per symptom                                                            |
+==================================================================================================+

    SYMPTOM: "could not connect to ollama server"
    FIX:     systemctl --user start ollama.service
             sleep 3
             curl -fsS http://127.0.0.1:11434/api/tags

    SYMPTOM: Service failed — port 11434 in use
    FIX:     ss -tlnp | grep 11434              find the squatter
             pkill -f "ollama serve"            kill stray host ollama
             systemctl --user restart ollama.service

    SYMPTOM: Wrong personality / wrong hardware info
    FIX:     cd ~/Avalhla/repo
             ollama create avalhla -f persona/avalhla.Modelfile

    SYMPTOM: Slow generation
    FIX:     Close Firefox, OBS, games. Check nvidia-smi.

    SYMPTOM: OOM / GPU spillover
    FIX:     avastop. Close apps. avastart.
             Or lower num_ctx to 8192 in Modelfile and rebuild.

    SYMPTOM: Nuclear reset (model corrupted)
    FIX:     ollama rm avalhla
             ollama create avalhla -f persona/avalhla.Modelfile
