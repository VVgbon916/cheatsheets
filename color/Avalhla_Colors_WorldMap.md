## 003 — HUMAN COLOR MODEL // SCIENCE-INSPIRED, STORY-ADAPTED

    Normal human color vision is trichromatic.
    Comparisons among signals from S-, M-, and L-sensitive
    cones support color perception.

    Important precision:
      - A frequently repeated "~1 million colors" figure
        is a rough communication-level estimate,
        not a fixed biological ceiling.
      - Individual color perception varies.
      - Chromatic adaptation changes how color appears
        in different contexts.
      - Metamerism allows different spectra to produce
        the same perceived color under an observer.
      - Tetrachromacy is included only as an optional
        fictional observer mode in this comic system.

    AVA'S NARRATIVE CEILING

      TARGET OUTPUT SPACE ~ up to 1,000,000 perceptual
                            states / scene
      NOT = 1,000,000 saved rows
      NOT = 1,000,000 immutable HEX values
      YES = a large variable state-space generated
            from anchors + context
