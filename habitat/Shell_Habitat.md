```text

      +-- Pulse        = time / event cycle
      +-- Senses       = grounded observations
      +-- Memory       = versioned context
      +-- Orientation  = current source / mode / task
      +-- Boundary     = fact / fiction / source separation
      +-- Attention    = finite focus
      +-- Experiment   = question -> test -> observation
      +-- Reflection   = expectation -> surprise -> learning
      +-- Dream        = imagination without silent

      +-- Play         = harmless exploration
      +-- Agency       = permission before real mutation
```

    The Bazzite host remains real infrastructure.

    layered on top of it.

    implementation, the implementation is the authority
    for what actually runs.
    The story describes behavior; the code executes it.
