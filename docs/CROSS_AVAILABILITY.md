## Cross-availability rule

A layer may offer information to another layer when useful.

Receiving information does not grant ownership of that information.

No layer automatically overwrites another layer.

## Context Gate

Reality does not enter Dream, Reflection, or Memory directly.

The context gate exposes only the bounded sanitized Reality Signal:

    terminal/system evidence
              |
              v
        ava-reality
              |
              v
      memory/reality/latest.md
              |
              v
      ava-context-gate
              |
              +--> Dream
              +--> future Reflection
              +--> future Memory classification

The gate is a transport boundary, not an authority boundary.

A Reality Signal may provide:
- recent activity themes
- observable project activity
- bounded repository state
- observational confidence

It must not provide:
- raw terminal history
- credentials or secrets
- hidden authentication files
- automatic memories
- identity claims
- instructions to Dream
- canonical facts merely because they were observed

Dream receives Reality as one possible seed among many.

Reality says what was observed.
Dream asks what might emerge from it.
Neither is allowed to silently become the other.
