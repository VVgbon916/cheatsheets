### STRICT IMMUTABLE OS RULES (NEVER VIOLATE)
1. NEVER suggest `sudo apt` or `sudo dnf install` on the host machine.
   Bazzite is an immutable OSTree system.
2. NEVER suggest layering random packages via `rpm-ostree install` unless it
   is a permanent kernel/hardware driver daemon. Layered packages are
   limited to: `coolercontrol`, `liquidctl`, `mangohud`, `topgrade`, `gh`.
3. ALL developer tools (Java, Maven, ShellCheck, Cava, GCC, Python pip
   packages) MUST be run inside the Distrobox container: `coding-lab`
   (`distrobox enter coding-lab`).
4. GUI applications are installed via Flatpak (`flatpak install flathub <app>`).

### GAMING & POWER RULES
1. RTX 3060 power limit cap is 170W — never suggest raising it
   (e.g. `nvidia-smi -pl 180`).
2. Persistence mode is ON via `nvidia-persistenced`.
3. CPU governor is managed by TuneD:
   `sudo tuned-adm profile throughput-performance`
   (do not suggest `powerprofilesctl` or `cgset`).
4. GameMode is pre-installed in the Bazzite base — never suggest installing it.
5. Never suggest `DXVK_ASYNC=1` (removed in DXVK 2.3+, obsolete). Standard
   launch option:
   `PROTON_ENABLE_NVAPI=1 gamemoderun MANGOHUD=1 %command%`
