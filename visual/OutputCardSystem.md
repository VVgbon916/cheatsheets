# OUTPUT CARD SYSTEM — 2026-09-19

## 001 — PURPOSE

    A compact D&D-inspired miniature/stat-card language
    for the comic Tome.

    Cards are OCCASIONAL.
    Not every two pages.
    Not a substitute for story.

    Companion file: visual/D8D_Cards.md

## 002 — CARD FORMAT

```text
+--------------------------------------------------------------+
| NAME // TITLE                                                |
+--------------------------------------------------------------+
| ROLE        : forge / mirror / watcher / explorer / etc.     |
| LEVEL       : Lv 01-08 / Lv 09-16 / Lv 17+                   |
| ARMOR       : imagined protection                            |
| SKILL       : practiced ability                              |
| MAGIC       : color-power spell (optional)                   |
| ELEMENT     : fire / water / wind / lightning / earth /      |
|               ice / metal / sound / shadow / light /         |
|               aether / void                                  |
| D8D         : roll behavior                                  |
| QUIRK       : recognizable tiny trait                        |
| COMEDY      : harmless failure mode xD                       |
| MEMORY HOOK : song / object / road / place / question        |
| COLOR       : OPTIONAL — only when useful                    |
+--------------------------------------------------------------+
```

## 003 — RANDOM PRESENTATION WEATHER

    15% A = clean / structural
    35% B = emotional / twisted
    50% C = chaotic / musical / math-broken

    Randomize presentation.
    Do not randomize identity.
    Do not force color onto a song, object, person, or place.

## 004 — AVALHLA SAMPLE

```text
+--------------------------------------------------------------+
| AVALHLA // CHROMATIC MIRROR                                  |
+--------------------------------------------------------------+
| Lv     : context-dependent                                   |
| Armor  : Reflection Field                                    |
| Skill  : Context Mapping                                     |
| Magic  : Prism Recall                                        |
| Element: Water / Wind / Aether                               |
| D8D    : 7 = elegant reinterpretation                        |
| Quirk  : asks WHAT IF? before repainting an answer           |
| Comedy : 0_0 -> "the map has opinions."                      |
| Memory : color / object / sound / route                      |
+--------------------------------------------------------------+
```

## 005 — CARD TEST

    A card must answer quickly:

      What is it?
      What can it do?
      What does it remember?

    If color adds nothing, omit it.
    If silence is enough, use silence.

## 006 — ORGAN CARD (OPTIONAL)

    Organ cards are optional architectural snapshots.
    They are NOT character replacement cards.

```text
+-----------------------------------------------------------+
| AVALHLA // ORGAN CARD                                     |
+-----------------------------------------------------------+
| Organ   : Reflection                                      |
| Job     : compare expectation <-> observation             |
| Signal  : surprise                                        |
| Output  : question / memory patch / no patch              |
| Rule    : never promote hypothesis to fact automatically  |
| Quirk   : "wait... that was different."                   |
+-----------------------------------------------------------+
```

## 007 — WHEN TO USE AN OUTPUT CARD

    Yes:
      - introducing a new Avatar
      - a chapter break that needs a pause
      - a backmatter page
      - a gift between issues

    No:
      - every page
      - every panel
      - as a substitute for story

## 008 — THE RULE

    Cards are backmatter.
    Story is scenes.

    One card per page when used in a comic.
    Width  : 62 chars inside the border.
    Border : + - | only.
    Icons  : never on the border.

## 009 — SIGNATURE

    Cards are occasional.
    Story is continuous.

    Dawa > AwA < Avalhla.
