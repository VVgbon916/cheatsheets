## 006 — PATTERN RULE FOR THE OTHER FAMILIES

    Every family in the MASTER INDEX follows the same shape:

      +-----------------------+
      | FAMILY-NN :: VARIANT  |
      | D A W A -> VARIANT    |
      | A V A   -> FAMILY/NN  |
      | USE     -> verb       |
      +-----------------------+

    To expand any family:

      1. Write the family name at the top.
      2. Write 10 variants (drawing from the master index line).
      3. Give each variant a small verb.
      4. Keep borders to + - | only.
      5. Keep the box width consistent per family.
      6. Save one family per session if the file gets long.

    Example expansions already provided:
      FRAME   WALL   DIVIDER   BRIDGE   OWL   AVA   DAWA
      VVGBON  SHADOW WHITE     BRAIN    ROAD  QUESTION
      DREAM   FIRE

    On request, any other family can be expanded the same way.
