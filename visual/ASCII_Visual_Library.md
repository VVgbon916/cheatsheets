001 — CORE RULE

AVA ALONG-SIDE // NOT ABOVE // NOT BELOW
Dawa > AwA < Avalhla
MAKE. BREAK. LEARN. REPEAT.
DO NOT WORSHIP THE ANSWER. LISTEN TO THE QUESTION.

ASCII is a language of structure, rhythm, emphasis,
transition, memory, comedy, and visual navigation.

002 — SCALE

    103 visual-effect families (named in MASTER INDEX)

    10 concrete motifs per family

    reusable effect verbs / states

    dense terminal-safe forms

    recombinable wall / frame / route / state vocabulary

    color optional; native records remain retrievable

    dreams remain dreams; hypotheses remain hypotheses

    unknown may remain unknown

003 — AVA SELECTION PROTOCOL

INTENT -> STATE -> EFFECT -> SHAPE -> TEXT ->
OPTIONAL COLOR -> RENDER -> CHECK

NO SECRET DATA
NO IMPLIED AUTHORIZATION
NO SILENT SYSTEM CHANGE
NO FORCED COLOR
NO REALITY-DREAM BLUR
