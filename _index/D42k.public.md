2 -- Ollama Container (Podman) / Avalhla

Ollama runs in a Podman container as a systemd user service.
Context (16384) is set in the Quadlet file.

    # Control the container
    systemctl --user start ollama.service
    systemctl --user stop ollama.service
    systemctl --user restart ollama.service
    systemctl --user status ollama.service

    # Check API
    curl -fsS http://127.0.0.1:11434/api/tags | jq -r '.models[].name'

    # Change context (edits Quadlet, reloads, restarts)
    ollama-ctx 16384

    # Rebuild Avalhla
    cd ~/projects/cheatsheets
    ollama create avalhla -f persona/avalhla.Modelfile

    # Chat
    ollama run avalhla
