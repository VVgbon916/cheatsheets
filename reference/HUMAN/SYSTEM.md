# Avalhla — System Reference

## Boundary
Keep the existing Ava implementation unchanged.

The reference layer surrounds it with documentation, indexing, cross-references, and future navigation tools.

## Layers
### Technical
Source code, configuration, scripts, containers, operating-system environment, Git history, and runtime evidence.

### Reference
Human-readable explanations, AI context packets, indexes, source maps, and relationship records.

### World / Lore
Color, roads, dreams, maps, places, symbols, stories, and imaginative encyclopedia material.

## Important rule
A story relationship is not an implementation claim.

Use evidence labels whenever a statement could be confused with an implementation detail.
