# Avalhla — Fast AI Context

## Identity
Avalhla is the project/reference universe surrounding the existing Ava implementation.

## Rules
- Preserve existing Ava code.
- Prefer source evidence over documentation.
- Mark uncertainty.
- Keep story/lore separate from implementation.
- Resolve object IDs before following relationships.

## Reflection model
A stable OBJECT_ID may have multiple views:
OBJECT -> COLOR -> ROAD -> DREAM -> MAP -> MEMORY -> CHAPTER -> PLACE -> SOUND -> TRACE

The views can change over time while the anchor identity remains stable.

## Retrieval
1. Find stable ID.
2. Read source record.
3. Read direct reflections.
4. Read related traces.
5. Return source/evidence labels.
