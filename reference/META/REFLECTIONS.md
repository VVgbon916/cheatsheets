# Avalhla — Reflection Map

This file is the human-readable relationship registry.

## Reflection vocabulary
COLOR — perceptual/index view
ROAD — route/path view
DREAM — imaginative/night/inner-world view
MAP — spatial/indexed view
MEMORY — remembered trace
CHAPTER — narrative grouping
PLACE — environment/location
SOUND — acoustic/contextual trace
TRACE — time-specific appearance or state

## Canonical relationship
ANCHOR -> REFLECTION -> TRACE

Example:
STONE-07
  COLOR  -> BLUE
  ROAD   -> RAIN-ROAD
  DREAM  -> WATER-DREAM
  MAP    -> WATER-EDGE-07
  MEMORY -> MEMORY-0378
  TRACE  -> TRACE-004

The example is schema documentation, not a claim that this object is currently implemented.
